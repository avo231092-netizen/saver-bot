# SaverBot

Telegram-бот для отслеживания подписок и цен на товары.

## Возможности

- 📋 Трекер подписок: добавление, список, напоминания за 3 дня до списания
- 💰 Трекер цен: парсинг Wildberries и Ozon, уведомления о снижении цены
- 📊 Статистика расходов и экономии

## Команды

- `/start` — главное меню
- `/add` — добавить подписку
- `/list` — список подписок
- `/track <URL>` — отслеживать цену товара
- `/stats` — статистика
